My Chrome extension "Github Bulk Delete" has 1.7k installs, 4.0 ratings based on 13 reviews. It's a public repository, https://github.com/flyingsky/github-bulk-delete. I don't expect it will have any great future, but at least some users like it. But 9/22/2026 I received one email from Chrome Web Store, "[Case: 42-1846502] Notification from Chrome Web Store about Github Bulk Delete". It's a great honer my chrome extension gets violation report from Microsoft. So I want to show the original email if you have no similar experience.

After asking Gemini, it reminds to change the chrome extension to "Bulk Delete for Github", and use Gemini to update every related information like the icon, title, etc, then republish the chrome extension like a new one. Now it's online again, https://chromewebstore.google.com/detail/bulk-delete-for-github/edooehnohlhhjmpccfplgbcoampmfpki.
